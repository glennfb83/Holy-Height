# Holy Height 💀

A tiny, single-file browser game about turning absurd inputs into **holy combinations**. Pick two items, run the calculator, collect BP (Battle Power), and complete the recipe codex.

> `raw milk + healthy = holy height` is the fictional meme premise. This project is satire, not health, nutrition, height, or medical advice.

## Play

Open [`index.html`](./index.html) in a browser, or enable GitHub Pages for the repository and visit the published site. No build step, server, dependencies, or account is required.

## Gameplay

1. Choose an input from the tile grid.
2. Choose a second input.
3. Press **CALCULATE THE HOLY RESULT**.
4. Discover recipes, earn Holy Points and BP, and climb the ranks.
5. Your progress is saved automatically with `localStorage`.

Unknown combinations still award a tiny amount of BP, so experimenting is always worthwhile. There are 24 hidden recipes, including combinations such as:

- `chicken + fire = holy food`
- `raw milk + water = holy hydration`
- `sleep + water = holy recovery`
- `calculator + crown = holy CEO`

## Tech

- Plain HTML, CSS, and JavaScript
- Responsive layout for desktop and mobile
- No external assets or libraries
- Local browser save data
- Small Web Audio click reward (which can be muted)

## Safety note

The looksmaxxing references are playful fiction. Do not consume unsafe combinations, use raw milk as a health treatment, or change your diet or body based on the game. Use real medical and nutrition professionals for real-world guidance.
